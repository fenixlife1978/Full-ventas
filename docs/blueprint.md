# **App Name**: Report Replicator

## Core Features:

- UI Replication: Replicate the existing UI design and layout from the provided URL (https://wild-green-thorn.agentui.app/reportes).
- Data Input Fields: Create input fields to collect data for the reports.
- Dynamic Report Generation: Generate dynamic reports based on the input data. The AI will act as a tool deciding whether to incorporate a certain information, after running logical comparison
- Report Export: Functionality to export the generated reports in various formats (e.g., PDF, CSV).

## Style Guidelines:

- Primary color: Slate blue (#778DA9) to evoke trust and professionalism.
- Background color: Very light gray (#EEEEEE) for a clean, neutral backdrop.
- Accent color: Soft green (#96C975) to add a touch of tranquility and signal correctness or validation.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look; suitable for both headlines and body text.
- Use minimalist, professional icons to represent different data types and actions.
- Maintain a clean, well-structured layout that is easy to navigate, replicating the structure of the provided URL.
- Incorporate subtle transitions and animations to enhance user experience.
